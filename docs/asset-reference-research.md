# Asset Reference Research

조사일: 2026-09-02

이 문서는 게임 에셋 제작을 위한 웹 레퍼런스 모음이다. venue 사진, 블로그, 웨딩 플랫폼, Instagram, YouTube 영상은 대부분 저작권이 있으므로 직접 복사하지 않는다. 픽셀 아트 에셋은 별도 라이선스가 명확한 경우에만 직접 재사용하고, 나머지는 색감, 형태, 공간 구성, 오브젝트 우선순위 참고용으로만 쓴다.

## 1. 최우선 제작 방향

라시따시어터 레퍼런스에서 반복적으로 확인되는 시각 언어:

- 높은 층고, 긴 버진로드, 큰 LED 스크린, 대형 샹들리에
- 아이보리/화이트 대리석, 골드 라인, 밝은 조명
- 블러쉬 핑크와 화이트 플라워, 짙은 그리너리
- 통유리 로비, 블랙 금속 프레임, 행잉 그리너리
- 신부대기실의 아치형 골드 프레임, 흰 소파, 커튼, 샹들리에
- 연회장의 넓은 뷔페 아일랜드, 우드 테이블/의자, 밝은 천장 트러스
- 양재IC/하이브랜드/양재시민의숲역 5번 출구/셔틀버스/주차 유도선

첫 에셋 배치는 아래 순서가 현실적이다.

1. 캐릭터: 하객, 신랑, 신부, 접수, 안내 NPC
2. venue 핵심 오브젝트: 유리문, 리셉션 데스크, 포토테이블, 꽃장식, 샹들리에, 소파, 축의대, 뷔페 테이블
3. route 오브젝트: 자동차 도로표지, 주차 유도선, 지하주차장 램프, 신분당선 역 표지, 출구 표지, 셔틀버스
4. UI: 대화창, 퀴즈 모달, 힌트 버튼, 화살표 안내, 시작/엔딩 버튼
5. OG 이미지: 1200x630 커버

## 8. 에셋별 제작 브리프

### 캐릭터 스프라이트

- 규격: 16x16 또는 32x32 원본, 게임 내 64x96 footprint에 안정적으로 배치
- 방향: down/left/right/up idle + walk
- 하객: coral 포인트, neutral outfit, label과 겹치지 않게 머리/몸 silhouette 단순화
- 신부: ivory dress, blush floral accent, gold hair/detail
- 신랑: greenery 또는 ink suit, ivory shirt, gold boutonniere
- 접수: gold/ivory desk staff 느낌, 너무 사람보다 안내 마커에 가깝게
- guide: coral/ivory 화살표 또는 리본 포인트

### HomeSelect

- 집 앞 문, 갈림길 2개, 자동차 route sign, subway stairs sign
- direct button과 trigger zone 모두 같은 시각 affordance 유지

### CarRoute

- 양재IC 주변 도로표지, 정체 차선, 파랑/분홍/노랑 유도선
- 지하3층 주차장과 타워주차장을 구분하는 컬러 라인
- 로고/상표는 그대로 쓰지 말고 `대형마트`, `주유소`, `꽃시장` 정도의 일반화된 실루엣으로 처리

### SubwayRoute

- 신분당선 계열 빨강/버건디 라인, 플랫폼, 역명판, 출구 번호 버튼
- 5번 출구를 정답으로 강조하되 색만으로 구분하지 말고 숫자/위치/문구를 같이 사용
- 유리 캐노피와 셔틀버스 표지판을 도착 오브젝트로 사용

### VenueLobby

- 통유리 로비, 행잉 그리너리, 리셉션 데스크, 웨딩 포스터, 포토테이블
- 신부 NPC가 포토테이블 근처에서 질문을 시작하는 구조
- 신랑측/신부측 축의대는 좌우 구분이 명확해야 함

### VenueHall

- 긴 aisle, 플라워 border, 샹들리에, 대형 LED 스크린, 골드 chair/candle detail
- 연회장으로 이어지는 화살표 안내는 floor decal 또는 리본형 arrow로 제작
- 뷔페는 ivory marble island + 우드 테이블/의자 + 음식 코너로 구성

### Ending / OG

- 커플 캐릭터, 작은 venue facade 또는 aisle, 꽃 프레임, 1200x630 title-safe 영역
- OG는 작은 카카오톡 미리보기에서도 신랑/신부 캐릭터와 결혼식 게임이라는 정보가 보여야 함
