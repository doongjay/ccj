# 로비 터치·얼굴·의상 후속 수정

이번 대화에서 추가 요청한 범위만 구현했다. 완료된 D 및 기존 검수 ZIP은 보존한다. 원래 검토 문서의 이전 규칙보다 이번 사용자의 구체적인 변경 요청을 우선했다.

## 변경

- 두 번째 얼굴 썸네일의 대괄호 같은 선 제거. 원인은 안경이 있는 얼굴만 넓은 영역(41,47,46,20)을 복사하면서 원본 머리의 눈 바깥 윤곽까지 가져온 것이었다. 공통 눈 영역만 복사하고 기존 안경을 같은 공통 함수로 그린다. 실제 캐릭터의 기존 남성 안경과 얼굴은 보존한다.
- 여성 1·2번 얼굴의 눈매를 둥글게 하고 짧은 속눈썹 추가. 여성 전용 썸네일 캐시와 공통 눈 합성 정의를 사용한다. 남성 얼굴과 세 번째 표정의 눈 간격은 유지한다.
- 여성 6번 검정 미니 원피스의 V형 카라 안쪽에 흰 나시 추가. 원본 검정 카라·기장·롱부츠·목 윤곽을 유지하며 피부가 드러난 가슴 부분만 옷감으로 채운다. 썸네일/큰 미리보기/걷기/사진/박수에 사용하는 공통 의상 파츠에서 처리한다.
- 지하철은 첨부 이미지처럼 하단에 다섯 개의 세로형 버튼, 각 버튼은 `1번\n출구` 식의 두 줄. 이전 대사와 오답 복귀 및 5번 출구 경로는 유지한다.
- 첫 로비 안내는 `도착! 로비가 넓군.\n어디부터 갈까?`. 배경은 45% 검정으로 어둡게 하고 중앙 말풍선을 터치해 닫는다.
- 로비의 ATM/웰컴드링크/제한 안내는 중앙에 배치하고 닫기 버튼 없이 터치/Enter/Space/Escape로 닫는다. 수첩/입장 조건 패널도 중앙 배치하며 필수 일정과 선택 액션은 보존한다.
- 웰컴드링크/ATM/포토테이블/축의대/포토부스는 로비에서 걷지 않고 즉시 열린다. 복귀하면 해당 시설의 유효 바닥 접근점에 선다. 일반 바닥 이동, 신부대기실 통로, 웨딩홀 접근은 유지한다.

## 근거

`before/`는 이번 수정 전 실제 브라우저 캡처다. `after/`는 수정 후 실제 화면과 정면 108개 조합의 native/4x PNG를 포함한다. `comparison/`는 같은 조건의 BEFORE(왼쪽)/AFTER(오른쪽) 비교다. `reference/`에는 사용자가 지정한 지하철 이미지를 보존했다.

실제 시간 영상, 개별 테스트 결과 및 실패 trace는 `runs/`에 있다. 실행별 JSON reporter는 `logs/`에 있다. 중단된 실행의 오류 및 미실행 항목도 삭제하지 않았다. 자동 동작 보존 검사와 시각 검수는 별도로 기록한다. idle과 동일하다는 결과를 얼굴 아트 품질 판정으로 사용하지 않는다.

검수 환경은 실제 Chromium 브라우저의 모바일 viewport 에뮬레이션이며 물리적인 iPhone/Android 검증은 아니다. 외부 배포/전송은 하지 않았다.

## 시각 판정 범위

정면108조합을 실제 공통 합성 함수로 생성해 남54/여54 native 시트를 확인했다. 얼굴 단품과 바뀐 의상6포즈는4x로 추가 확인했다. 기존 남성54개는 이전 완성본과 픽셀이 동일하다. 여성36개는 얼굴1/2 눈매 변경, 추가3개는 얼굴3+6번 의상 나시 변경이다. 총39개 합성 변경이며 세 번째 눈 간격과 목·턱·의상 윤곽을 무관하게 바꾸지 않았다.

실제 표시 확인:3폭의 로비/지하철/남녀 커스터마이저, 여성1/2 썸네일/큰 미리보기, 대표3프로필의 실제 깜빡임·걷기·부스/신부 사진·단체사진·박수·저장 복구. 정상 속도 원본 영상은 runs/flows-01, 최종 터치 영상은 runs/after-04. 사진 결과는5.5초 유지한 뒤 사용자 동작으로 복귀한다. group-photo.png는 원래 테스트의 셔터 플래시 시점이며 마지막 녹화 프레임도 별도 추출해 표시했다. 영상 배속·보간·실패 구간 편집 없음.

최종 UI판정은 실제 screenshot을 보고 내렸으며, 동작과 idle의 일치 검사는 아트 품질 판정과 별개다. 모든 정면 조합 생성/확인과 대표3개 실제 플레이 검증을 구분한다.

## 검수 ZIP 구성과 원본 보존

원본 실행 폴더/trace/반복 캡처는 삭제하지 않았다. 큰 전체 trace와 중복 iteration은 검수 ZIP에서만 제외하며 EXCLUDED_FILES.json에 경로/크기/사유를 기록한다. 실패 reporter·오류 context·trace의 이벤트/네트워크/스택/화면 자료를 failure-trace-details에 보존했다. 이는 전체 trace의 복사본이 아니라 실패 원인 확인용 추출이며 전체 원본 경로는 index.json에 있다. 일부 중단된 trace의 불완전한 종료 오류도 숨기지 않았다.

앞선 `minimi-silhouette-fix-review.zip`의 SHA-256이 그대로임을 source-fingerprint.json에서 확인했다. A/A1/B/C/D의 원본 검수 패키지를 덮어쓰지 않았다. F24 전역 아트 재가공/F25를 시작하지 않았다.

전체 trace 화면 추출은 원본 폴더에 보존했다. 검수 ZIP에서는 정지 대기 화면의 반복 스크린캐스트를 줄여10초 간격 및 마지막5장만 포함했다. 모든 필수 AFTER PNG와 실제 시간 원본 영상은 그대로 포함한다. 제외 경로·크기·사유는 EXCLUDED_FILES.json에 있다. 첫 포장본(전체 반복 trace 화면 포함)은 `../touch-face-refinement-review-full.zip`으로 별도 보존했다.
