## 검수 자료

- `after/inspection/male-all-54-front-native.png`, `female-all-54-front-native.png`: 실제 게임 합성기의 남녀 전체 정면. 각각 54개, 총 108개.
- `after/inspection/*all-54-neck-4x.png`: 전체 접합부 nearest-neighbor 4배. `after/atlas/page-*`에는 축소하지 않은 3조합씩의 native/4x 페이지도 있다.
- `after/registry.json`: 실제 0-based ID, 얼굴·헤어·의상 이름. 2성별 × 3얼굴 × 3헤어 × 6의상. 전부 렌더링했고 전부 정면 시각 검수했다.
- `after/atlas/part-*`, `layer-*`, `source-*`: 얼굴/헤어/의상 단품, 원본/합성 레이어. 머리 레이어는 원본 좌표이며 최종 조합에서만 y+3 등록이 적용된다.
- `comparison/`: 사용자 세 조합의 같은 393×852 조건, native 미리보기 4x, 실제 로비/개인사진/신부사진/반응/단체사진 BEFORE/AFTER.
- `after/flows/`: 7대표 조합의 실제 정상 플레이. 108조합 전부의 전체 여정을 플레이했다고 주장하지 않는다.
- `after/motion/`: 13대표의 정면/좌/우/뒤/포즈/착석/깜빡임/걷기/박수 19프레임. 걷기·박수는 공통 프로덕션 atlas에서 추출했으며 실제 여정 영상과 구분한다.
- `after/ux/`: 지하철·터치 진행·여성6의 320×568 / 393×852 / 430×932 화면. 사용자 세 조합 선택 화면은 위 세 크기와 1440×900도 검사했다.
- `after/neck-loading-ux/`: 기존 로딩·자동차 세 경로·첫 수첩·촬영 프레임·뷔페 회귀 증빙.
- `TEST_RESULTS.json`, `logs/`: 개별 결과를 포함하는 reporter, 실패·중단·재실행 기록. shipping 검사는 테스트 집계와 별도로 `assets-final-01.json`에 기록한다.
- `VIDEO_INDEX.json`: 원본 정상 속도 영상 경로·시간·크기. 배속, 프레임 보간, 실패 구간 삭제, 재인코딩을 하지 않는다. 두 사진 결과를 각각 5.5초 이상 두고 직접 복귀하는 구간을 유지한다.
- `source-fingerprint.json`: 검증한 dirty working tree의 실제 내용 해시. HEAD만으로 변경 버전을 표시하지 않는다.

## 실행

`game/package.json`에 정의된 `dev`는 `vite`다. `game/`에서:

```sh
npm run dev -- --host 127.0.0.1 --port 5174 --strictPort
```

접속: http://127.0.0.1:5174/ . 외부 배포는 하지 않았다.
