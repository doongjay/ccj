정면 전수4×30페이지는 최종 캡처와 실제 검수한 iteration02 페이지가 바이트 동일함을 추가로 대조했다. 이후 수정은 옆얼굴과 extra raised-hand 등록이며, 최종 11대표 동작 페이지를 다시 확인했다. 해당 동일성은 이미 본 이미지의 버전 연결 근거이고, 이미지가 정상이라는 판단을 대신하지 않는다. `diagnosis/body-preservation.json`에 페이지별 해시와 90 idle의 몸 y≥100 불변 근거가 있다.

실제 정상속도 영상3개는 입력→반응→전환과 각 사진5.5초 감상·직접 복귀를 전부 보존한다. 영상 전부를 플레이어에서 시청했다고 주장하지 않으며, 실제 관찰한 자료는 화면 PNG, blink 연속 프레임, 원 영상에서 추출한 PTS 반응 프레임이다. `videos/index.json`은 원 영상의 길이/해시와 추출 시간을 기록한다. 작게 축소한 영상 속 캐릭터만으로 시각 합격시킨 것이 아니라 source-native/4× 확인과 함께 판정했다.

## 사용자 불만별 확인

- [x] 머리–목–몸: 웨이브의 목 기준점 교정, 공유 neck 음영, 추가4의상의 posing neckline 등록으로 접합부 어긋남/틈을 제거했다. 정면90과 동작대표11 확인.
- [x] 얼굴: 남성 첫 얼굴 썸네일의 `[ ]`는 원래 옆머리/턱 edge의 잘못된 crop이므로 얼굴 feature만 복사한다. 실제 머리 외곽은 자연스러운 외곽으로 남고, 얼굴3의 흰/회색 잔여 픽셀과 방향별 오래된 눈은 실제 texture에서 제거했다. 안경은 선택한 경우 유지한다.
- [x] 목: 피부색 연결만 남기지 않고 짧은 턱밑 음영/측면 윤곽이 카라와 이어진다. 파란 셔츠와 아이보리 라운드 상의 모두 확인했다.
- [x] 의상: 아이보리 목의 정상 rim을 피부 이웃 분류가 지워 끊기던 문제를 수정했다. 잔재를 배경색으로 가리거나 작은 connected component 삭제 조건을 확장하지 않았다.

실제 iPhone/Android, WebKit/Firefox 및 D F22 OS키보드/주소창/safe-area 범위는 미검증으로 유지한다. Chromium DPR1의 실제 브라우저 화면과 다른 기기의 물리 화면을 혼동하지 않는다.
