# 세 번째 표정 눈 간격 조정

`game/src/ui/classicMinimi.ts`의 세 번째 정면 표정 눈 중심을 (50,78)에서 (51,77)로 조정했다. 양쪽을 각각 정수 1픽셀씩 안쪽으로 옮겼으며 남녀 썸네일·미리보기·정면 게임 스프라이트·사진 포즈·깜빡임에 공통 적용된다. 기존 지우기 영역과 다른 표정, 측면, 목·카라는 유지했다.

실제 브라우저 기존 검사 3건 PASS: 사용자 세 조합의 320×568 / 393×852 / 430×932 / 1440×900 미리보기와 A-B-A 일치, 실제 합성기 108조합 출력, 대표 세 번째 표정의 깜빡임·걷기·두 사진 촬영과 5.5초 감상·복귀·이어하기·박수·단체사진. console/page error 없음. 개별 결과와 영상 최종 경로는 `tests.json`, 전체 출력은 `tests.log`다. 사용한 임시 config는 같은 폴더에 복사했다.

`face3-before-after-4x.png`의 남녀 각 세 헤어를 직접 확인하고 393×852 썸네일·미리보기·실제 로비·포토부스 결과 화면을 확인했다. `pixel-comparison.json`: 실제 정면108개 중 세 번째 표정36개만 눈 영역에서 변경되었고 다른72개는 동일하다. 전체108개를 각각 게임 끝까지 플레이했다는 의미는 아니다.

BEFORE는 직전 검증 소스의 SHA256이 현재 수정 직전 파일과 같음을 확인한 뒤 이전 AFTER를 복사했다. 이전 검수 폴더·ZIP은 수정하지 않았다. 코드 diff는 `change.patch`, 수정 파일 SHA256은 `source.json`이다.
