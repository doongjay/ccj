# 이재준 ♥ 김현서 결혼식 — 게임형 청첩장 개요

## 1. 프로젝트 한 줄 요약

게더타운 스타일의 실시간 이동형 픽셀 게임으로, 하객이 "집에서 결혼식장까지 가는 길"을
직접 캐릭터를 움직여 퀴즈를 풀며 도착하는 모바일 웹 청첩장.

## 2. 결혼식 기본 정보

| 항목 | 내용 |
|---|---|
| 신랑 | 이재준 |
| 신부 | 김현서 |
| 일시 | 2026년 11월 21일 오후 2시(14:00) |
| 장소 | 라시따시어터(LACITTA) — 서울특별시 서초구 매헌로 16, 1층 그랜드볼룸 |
| 실명 노출 | 청첩장에 성함 그대로 노출 (별도 익명화 없음) |

## 3. 핵심 컨셉

- **장르**: 탑다운 픽셀 어드벤처 + 퀴즈(트리비아) 하이브리드
- **플레이어**: 하객을 대리하는 단일 캐릭터 (신랑/신부 커스터마이징 없음)
- **스토리 축**: "집 → (자차 or 지하철) → 결혼식장 로비" 로 이어지는 여정을 따라가며,
  분기마다 실제 상황을 반영한 퀴즈를 풀어야 다음 장면으로 넘어감
- **톤앤매너**: 유쾌하고 위트 있는 톤 (예: 양재IC에서 막히는 장면을 실감 나게, 오답 시
  장난스러운 리액션)
- **오답 처리**: 막히지 않고 재시도 가능 + 힌트 제공 (하객이 스트레스 없이 완주하는 것이 우선)

## 4. 플랫폼 & 배포

- **타깃 환경**: 모바일 웹 전용 (카카오톡 등으로 링크 공유 → 스마트폰 세로 화면에서 플레이)
- **조작**: 화면 탭투무브(Tap-to-move) — 별도 버튼/조이스틱 없이 직관적으로 이동
- **기술 스택**: Phaser 3 (자세한 내용은 [design.md](./design.md) 참고)
- **공유**: 카카오톡 공유 시 링크 미리보기(OG 이미지/문구) 노출 필요

## 5. 게임 구조 요약

```
인트로(초대 오프닝)
   │
   ▼
집 — 갈림길 선택: [자차로 간다] / [지하철을 타고 간다]
   │                              │
   ▼ (자차 루트)                  ▼ (지하철 루트)
양재IC 정체 장면                 환승/노선 확인
   │                              │
   ▼                              ▼
퀴즈: 유도선 색깔 선택            퀴즈: 양재역 출구 번호
   │                              │
   └────────────┬─────────────────┘
                 ▼
         예식장 로비 도착 (두 루트 합류)
                 │
                 ▼
   공통 스테이지: 포토테이블 → 신랑측/신부측 확인 → 축의대 안내 → 뷔페 동선
                 │
                 ▼
      엔딩: 식사 후 집에 가는 길 — 신랑신부 캐릭터 + 갤러리
```

세부 대사, 퀴즈 문항, 힌트 문구는 [scenario.md](./scenario.md)를,
실제 공간 재현 기준은 [map.md](./map.md)를 참고하세요.
