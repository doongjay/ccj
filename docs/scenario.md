# 시나리오 문서

전체 여정: **집 → (자차 or 지하철) → 예식장 로비(합류) → 접수/뷔페 안내 → 엔딩**

톤앤매너: 유쾌하고 위트 있게. 오답이어도 하객이 부담 갖지 않도록 장난스러운 리액션 +
바로 재도전 가능한 흐름을 유지한다. 정답을 맞히지 못해도 게임이 막히지 않아야 한다
(재시도 + 힌트 방식, [introduction.md](./introduction.md) 참고).

---

## 0. 인트로

- 링크 접속 시 타이틀 화면: "이재준 ♥ 김현서의 결혼식으로 가는 길" (가제, design.md 카피 참고)
- 신랑신부 픽셀 캐릭터가 인사하는 짧은 연출 → [시작하기] 버튼
- 짧은 도입 대사로 플레이어에게 미션 부여: "오늘 하객님을 예식장까지 무사히 모셔다드리는 게 저희 임무예요!"

## 1. 집 — 갈림길 선택

- 집 앞(문 앞) 장면에서 플레이어가 두 갈래 길 중 하나로 캐릭터를 이동시켜 선택
- 선택지
  1. **자차로 간다** → Route A로 진입
  2. **지하철을 타고 간다** → Route B로 진입
- 이후에는 되돌아올 수 없음(한 번 고른 루트로 엔딩까지 진행). 재플레이 시 다른 루트 선택 가능

---

## 2. Route A — 자차

### A1. 양재IC 정체 (스토리 비트, 퀴즈 아님)

- 캐릭터가 차를 타고 이동하는 연출 → 양재IC 부근에서 화면이 정체 상황으로 전환
- 연출 대사 예시: "어... 양재IC인데 오늘따라 왜 이렇게 막히지?" / "역시 결혼식 가는 길은 순탄하지 않다"
- 화면 전환과 함께 A2 퀴즈로 자연스럽게 이어짐

### A2. 퀴즈 — 어떤 색 유도선을 타고 가야 하지?

| 선택지 | 결과 | 판정 |
|---|---|---|
| 노란색 유도선 | 이마트 주차장으로 안내 (요금 발생) | 오답 |
| 핑크색 유도선 | 타워 주차장 (불편함) | 오답 |
| 파란색 유도선 | 지하 3층 주차장 (예식장 직결, 좋음) | **정답** |

- **정답**: 파란색 → 지하 3층
- **오답 리액션(공통 톤)**: 살짝 코믹하게 되돌아오는 연출 + 힌트 버튼 노출
  - 노란색 선택 시: "어라, 여기 이마트인데요? 주차비 정산하고 다시 나가볼까요?"
  - 핑크색 선택 시: "타워 주차장은 계속 뱅글뱅글... 어질어질하네요. 다른 색을 찾아봐요."
- **힌트 문구**: "지하로, 아주 깊숙하게 내려가는 길이 제일 편하다고 하던데요?"
- 정답 시: 주차 완료 연출과 함께 Route A → 합류 지점(3장)으로 이동

> TBD: 자차 루트를 3단계(미디엄)로 늘릴지 여부. 늘릴 경우 "주차 후 엘리베이터/로비 진입"
> 스테이지 추가를 제안하되, 현재는 2단계(정체 연출 + 유도선 퀴즈)로 미니 구성 확정.

## 3. Route B — 지하철

### B1. 노선 확인 (스토리 비트, 퀴즈 아님)

- 캐릭터가 지하철을 타고 이동하는 연출
- 대사 예시: "양재역은 3호선이랑 신분당선이 만나는 곳이니까 헷갈리지 않게 조심하세요!"

### B2. 퀴즈 — 양재역 몇 번 출구로 나가야 하지?

| 후보 | 정답 여부 |
|---|---|
| 1번 출구 | 오답 |
| 4번 출구 | 오답 |
| 5번 출구 | **정답** |
| 7번 출구 | 오답 |
| 8번 출구 | 오답 |

- **정답**: 5번 출구
- **오답 리액션**: 엉뚱한 출구로 나가 다시 계단을 내려가는 짧은 연출 (예: "어? 여기서 나가면 반대편인데요, 다시 내려가 볼까요?")
- **힌트 문구**: "라시따시어터 방향은 홀수도 짝수도 아닌... 딱 중간, 5번이에요!" (또는 실제 출구
  기준 설명으로 교체 — 아래 TBD 참고)
- 정답 시: 출구로 나와 도보 이동 연출과 함께 Route B → 합류 지점(3장)으로 이동

## 4. 합류 — 예식장 로비 도착 (공통 스테이지)

두 루트 모두 이 지점에서 합쳐지며, 이후 진행은 동일하다.

### C1. 포토테이블 확인 → 접수대 분기

- 예식장 로비에 도착하면 포토테이블 앞에서 신부 캐릭터(NPC)가 말을 걸어옴
- 신부 캐릭터에게 말을 걸어야(포토테이블 확인) 다음 질문이 진행됨: "누구 쪽 손님이세요?"
- 선택지: **신랑측 친구** / **신부측 친구**
- 선택에 따라 올바른 축의대로 안내
  - 신랑측 친구 → 축의대 1 (지도상 포토부스 인근)
  - 신부측 친구 → 축의대 2 (연회장 입구, 신부대기실 복도 방향)
- 오답(반대쪽으로 이동 시도) 시: "어이쿠, 그쪽은 반대편 축의대예요!" 안내 후 재시도

### C2. 뷔페(연회장) 동선 안내

- 축의대에서 접수를 마치면 연회장(뷔페) 방향을 안내하는 짧은 길찾기 연출
- 퀴즈보다는 가이드 성격 (필요 시 간단한 방향 선택 퀴즈로 확장 가능 — TBD)

## 5. 엔딩 — 식사 후 집에 가는 길

- 하객이 식사를 마치고 집으로 돌아가는 장면으로 자연스럽게 전환
- 신랑, 신부 캐릭터가 함께 등장해 감사 인사
- 사진 갤러리 노출 (커플 사진들)
- 마무리 CTA: 축하 메시지/방명록 등 (design.md에서 실제 UI 컴포넌트로 구체화)
- 엔딩 카피 톤: 유쾌하되 마지막은 진심으로 — "오늘 와주셔서 정말 감사해요, 조심히 들어가세요!"
