# 제공 사진과 공간 적용 기준

기존 픽셀 스프라이트·폰트·패널·게임 진행을 유지한다. 사진은 구조와 방향 참고이며 실사 사진을 게임 배경에 붙이지 않는다.

## 방향 기준
- 로비 화면 아래 = 셔틀에서 내린 뒤 들어오는 유리 출입구. 왼쪽 벽은 유리창이 아니라 대리석 벽.
- 입구 정면 위쪽 = 공용 축의대 하나. 시작 시 선택한 신랑측/신부측 정보로 접수한다.
- 왼쪽 = 장식용 휴게 좌석과 포토월/포토부스. 웰컴드링크는 아래쪽 오른편 벽에 붙여 좌석과 마주 보게 배치. 휴게공간 메뉴 없음.
- 중앙 = 축소한 에스컬레이터. 오른편 휴게 코너 뒤쪽은 화분 선반이 왼쪽, ATM이 오른쪽이며, 앞쪽에 테이블·등나무 의자가 놓임.
- 축의대 옆 부모님은 신부측 선택 시 분홍 치마, 신랑측 선택 시 하늘색 치마의 어머니와 정장 아버지로 표시. 하객 이름표는 숨기고 시설 명패는 유지.
- 포토테이블 쪽 갈림길 = 위 연회장, 오른쪽 웨딩홀. 문구와 버튼을 중복해서 겹치지 않는다.
- 아래 오른쪽 = 신부대기실 잔디 통로. 신랑측은 로비 안내 팝업으로 진입 제한.

음식 6장은 앞선 요청대로 따뜻한 손그림 음식 일러스트를 유지한다. 나머지 공간은 픽셀 배경이다.
포토테이블에 덧씌웠던 별도 작은 소품 이미지는 제거했다. 갤러리의 과거 가상 웨딩 아치 샘플은 제공 공간을 반영한 본식/포토월 이미지로 교체했다. 실제 커플 사진은 이 세션에서 제공되지 않았다.
